# Community awareness sessions

Reports from real cyber awareness sessions run by CyberSecTOBER contributors: in markets, churches and mosques, schools, offices and family groups. Each report shows what was shared, who it reached and what people asked, so others can run their own.

**How to add one:** run a short session (even 15 minutes with 5 people counts), then create a new file in this folder named `your-github-username-community-yyyy-mm-dd.md` using [`templates/session-report.md`](../../templates/session-report.md). The [Shield Up game](https://cybersectober.github.io/Cybersectober/play/) can build your awareness kit and fill in the report for you.

**Rules:**

- Never include anyone's full name, phone number, address or account details.
- No photos of children. Only share photos of adults who agreed, and keep faces out if you are unsure.
- Describe scams people mentioned without naming real victims.

Session reports earn **5 points** and the **Community Defender** badge. If several people ran the session together, list everyone's GitHub username under "Squad" so mentors can credit the team.
